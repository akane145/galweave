## 对原报告的修正

1. **B1 成立，且有语义问题。** 开工时 `style.css:4590` 的字符对勾与 `2738` 起的 CSS 图形叠加。普通已译行还显示绿色对勾，而 `rowStatusInfo()` 将未校对译文定义为 pending；图形应从行的 `data-state` 取四态，避免将“已译”误示为“已定稿”。
2. **B2 成立，B2b 必须分项核对。** 主操作和部分激活按钮仍使用亮底白字；但批注角标 `.pr-badge` 已被开工时 `style.css:2711` 的 soft 配色覆盖，不能拿早期 `710` 行的声明计算实际对比度。验收以浏览器最终样式和语义前景配对为准。
3. **B3/B4 成立。** 新截图可见顶部 toast 覆盖工具区、搜索导航被截断并有横向滚动条；布局应换行，不能只用 overflow:hidden 隐藏内容。
4. **虚拟列表约束需澄清，并有实际错位。** `renderer.js:124` 的 `measureRow()` 测量实际行高，`1056` 起的 ResizeObserver 在宽度变化时重新测量。修改 padding/border 不必机械地修改高度模型；行间 margin/gap 则必须与 `ROW_GAP_BY_DENSITY` 一致。200 段运行时检查进一步发现开工时 `style.css:3341` 的 compact 行距为 `var(--sp-2)` 即 8px，而 renderer 使用 6px。本次将 CSS 修到现有模型约定的 6/12/20px，并加入样式与模型配对检查。
5. **T-01 不采用全库计数门禁。** 固定“第 300 行以后”以及白色、零圆角、`!important`、字距总次数，不能证明渲染正确；重排 token 就可能误报，合法形状/可访问性规则也会被误伤。替换为颜色配对、目标组件回归断言和浏览器布局测量，不新增任意维护阈值。
6. **T-10 的热区说法不成立。** 行内“通过”“有问题”“批注”是独立动作，整行可点击不能代替各按钮的热区。它们按项目已有 `--hit-min` 保证独立热区。
7. **T-13 限定中性色作用域。** 仅将待校对行的徽章、行号图形和脊线降为中性；不全局重定义 `--st-pending`，以免容量告警、危险替换提示等共用语义被一起改灰。
8. **T-14/Q2 保留外置引号与全宽编辑器。** 右引号贴“文本末尾”不是简单 flex 对齐，遇到多行、输入法和用户字体需新增文本测量或编辑结构。此次统一字体与样式，保留已有括号保护和编辑宽度，不将它并入可编辑内容。
9. **T-17 不以全库“无 emoji”验收。** 替换操作按钮和状态图形；文本通知、导出报告、测试中的脚本字符不属于图标替换范围。`rowstatus.js` 的纯逻辑返回协议保持兼容，在渲染层映射 SVG。
10. **工期分项有算术误差。** 按原表逐项相加，高优先级为 6.0 人日，中为 8.0，低为 2.5，总计仍为 16.5。该数字是原作者的规划估算，不作为本次实际耗时或质量判断。
11. **T-19 的 18% 不作为硬门槛。** 1280×800、侧栏开启时，折叠后首张卡片顶部实测约 159px，相比原截图约 208px 减少约 49px。继续压到 144px 会挤掉卡片顶部留白或按钮热区。本次验收要求默认折叠、键盘可展开、操作可用，记录实际高度而不为主观百分比牺牲可用性。
12. **换行需要同步主区高度。** 首轮集成发现切换搜索后顶栏从 94px 增至 182px，原有 `main.style.height` 仅在窗口 resize / 打开侧栏时更新，造成底部裁切。本次让模式切换立即同步，并观察顶栏、底栏实际高度变化，覆盖字体加载和响应式变化。
13. **底部定位必须有有效 token。** 旧样式引用但未定义 `--statusbar-h`，使 toast 的 `bottom:calc(...)` 无效。补齐 v4 已定义的 32px 状态栏尺寸，并在浏览器检查实际 bottom、与底栏的位置关系，不能只检查 CSS 中出现了 bottom 或标题恰好未重叠。

## 设计选择

- Q1：待校对行降为中性，警示色语义保留。
- Q2：保留外置引号，不承诺贴文本尾；理由见上。
- Q3：连续校对使用默认收起的原生 details，操作和快捷键仍保留。
- Q4：普通非激活行只显示状态形状，激活行和校对模式显示完整标签，保留稳定占位与可访问状态。
- Q5：浅色画布略灰、卡片亮色；背景图与透明度功能保持。

三主题、1280×800 / 960×600、搜索和侧栏开关、四种行状态、弹窗与 toast、连续校对展开收起、浏览器机翻入口、现有单测与 lint，以及普通/单文件前端构建。截图、运行时 JSON 与最终命令结果在完成时记入 `todo.md`。不包含 Windows 安装包重打包或真实机翻服务调用。

# 手动翻译与连续校对

用户选择：两者都做，先解决输入与定位，再完善校对流程。

1. 高 / 1–2 人日：输入法确认不切行；组合键不被局部 Enter 处理吞掉；Shift+Tab 不被建议采纳截获。普通字母留给输入，新默认审校键为 Alt+Enter / Alt+W / Alt+A。
2. 高 / 1–2 人日：按文档保存会话内的活动行、选区、视口锚点和校对筛选；提供返回编辑位置按钮。使用既有虚拟列表，不复制渲染层。
3. 高 / 2–3 人日：待校对、检查与问题、未解决批注三个实时队列；复用 proof / qa 的分析结果，支持前后导航、暂留、通过并继续及完成提示。

边界：位置只保存在当前应用会话的标签快照中，不承诺重启恢复；浏览器单文件入口仍是原有行为。“暂留”不改变状态，不从未完成总数里移除。人工通过不自动解决批注或忽略 QA，所以检查与问题队列会保留实际仍有问题的行。

本轮不包含前一轮建议中的原子保存、机翻任务管理、编码和记忆库扩展，也不增加字词级 diff。它们是后续独立改动。

验证：纯函数单测、proof 状态回归、全套 node 测试、Vite 构建、隔离 Chromium 合成对白交互验证。浏览器验证脚本不访问用户文件或翻译服务。

# tasks/ — 设计与实施记录

本目录存放**功能级的完整设计与实施记录**：一份方案文档 + 一份可勾选的实施清单。
它与 `docs/` 的分工是：

| | 内容 |
|---|---|
| `docs/` | 面向**使用与维护**的长期文档（用户指南、维护契约、集成说明、发布说明） |
| `tasks/` | 面向**单个功能**的设计决策与实施过程记录（含当时的取舍理由、验收标准、偏差说明） |

维护约定：

- 只放 `.md`。临时产物、脚本、截图不要放这里（该目录已不整体忽略，见 `.gitignore` 的说明）。
- 一个功能一组 `plan.md` + `todo.md`。若将来有第二组，改为按功能建子目录。
- **完成后不要删除**。记录的价值在于"当时为什么这么定"——结论会写进 `docs/`，但取舍理由留在这里。
  完成状态在 `todo.md` 里勾选，偏差在末尾「遗留说明」里如实写明。

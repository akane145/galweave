- [x] 完全不懂正则的用户能用至少两组样例建立包含对话和旁白的档案。

- [x] v1 档案、默认解析器、镜像格式和单文件 HTML 构建均无回归。（3 个内置 v1 档案仍有效且仍按 v1 解析；两种构建均成功）

## 遗留说明

- `tasks/plan.md` 的「Not Doing」各项均未触碰：不做无译文槽的文件、不做嵌套语法树/转义字符串/二进制脚本、不用大模型猜规则、不暴露正则与插件回调、不做引擎预设、前后缀仍作为固定 literal。
- 档案里**不保存用户粘贴的原始样例**（只存归纳出的规则），因此用「使用档案」回填时样例框显示的是模板形态的占位，用户粘贴真实样例后需重新标注。这是 plan.md 风险表里"保存大量样例撑大 settings"的既定取舍。

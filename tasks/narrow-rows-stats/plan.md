# 正文对齐并调整字数统计位置

用户希望单行不要横跨过宽的阅读区域，并希望翻译字数统计更醒目。

- 正文行宽保留随视口扩展的舒适阅读尺寸，窄屏按可用宽度铺开，不调整引擎字节或字位阈值。
- 原文与译文正文共享水平起点；每行按当前字体实测原名与译名中较宽者确定说话人列宽，列间距为零、姓名前留约 8px 内边距。姓名以普通文字呈现，不加仿对话框名牌或背景；NAME 行保留可编辑译名。
- 原文、译文、原名与译名采用一致的默认 17px 字号与行高；原译默认使用同一无衬线字体族，仍尊重主题设置中明确指定的字体/字号。带括号行的开括号从原文正文起点对齐。
- 将唯一的 `#stats` 移到左侧项目区，继续走既有 `updateStats()`；单行显示 `字数 译文字符数 / 原文字符数`，其标题和无障碍名称分别说明两个数字；无打开文档时隐藏。底栏不显示“已翻译 N/N”，隐藏的 `#progress` 保留既有同步数据链路，完成度继续由左侧进度显示。
- 稿页恢复校对工具栏 / 虚拟滚动列表两行结构；窄屏固定工作区高度，让列表独立滚动并使侧栏默认收起。

验收：原文与译文正文起点相同；人名无冒号且贴近同一行正文，留白位于姓名前；有名对白与旁白都保持原译正文对齐，原名/译名普通文字显示且 NAME 行只显示原名一次并可编辑译名；带括号行开括号对齐原文首字；四种文字默认字号协调且保留用户自定义原译字号；左侧字数统计单行显示译文/原文字符数、实时变化并在空项目隐藏；底栏无可见行进度数字；校对模式可滚动；390px 窄屏无正文横向溢出。

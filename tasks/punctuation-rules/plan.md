# 自定义标点规则

- 高 / 0.5 人日：复用 textnorm，支持字面量匹配、替换、删除、启停和顺序；每条只执行一次。
- 高 / 0.5 人日：规则编辑、示例、即时试用、完整逐行预览和撤销；预览过期则拒绝应用。
- 中 / 0.25 人日：普通文档保存到 settings.ui；记录包文档只保存本包配置，并随记录包传递。
- 高 / 0.5 人日：验证控制符保护、括号不重复包裹、纯逻辑及浏览器闭环。

示例：`。」 → 」`、`……。 → ……`、`……—— → ……`。第三项可将替换文字改为 `——`。示例需主动加入，不改变既有默认效果。

限制：最多 100 条，每侧最多 200 个 UTF-16 码元；匹配不能为空，不支持跨行、脚本控制符与正则表达式。内置规则先执行，自定义规则按列表顺序各执行一次。

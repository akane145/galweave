# Galweave → Obsidian / 译间

## 一键导出修改意见（2026-09-17）

在侧栏 **校对** 页顶部点击 **导出校对意见**，即可汇总当前脚本中有批注或保留改译历史的条目。每项包含日文原文、修改前译文、当前修改后译文、已有批注及其解决状态，附角色与编辑器段落号。

- 桌面版直接保存到已配置库的 **校对意见/** 目录，默认是 `E:/Codex/Obsidian/汉化校对积累/校对意见/`；每次生成新报告，不覆盖旧报告。
- 浏览器版直接下载 Markdown，可放入 Obsidian 阅读。
- 同一句多次修改，取当前保留历史中最早的旧译与当前译文。新版本不设记录条数上限；旧版本曾截断的最早文本无法恢复。
- 有批注但没有旧译记录时，报告明确标注缺失；有改译但没有批注时，标注未填写修改意见。不会自动生成或猜测你的改译理由。
- 导出全部相关记录，修改列表也完整展示所有对比。译名改动与正文改动分别列出。

这是供阅读与分享的汇总报告，可在 Obsidian 自由修改；它与“收藏到 Obsidian”生成的结构化经验卡用途不同，不会作为译间的单条案例读取。

这是一条人工挑选后的单向收藏流程：在 Galweave 完成校对，收藏值得积累的修改，在 Obsidian 补充和学习，在译间检索案例。无需安装 Obsidian 插件，无需运行译间服务即可导出。

## 怎么使用

1. 使用本次重新构建的桌面程序：GitHub Releases 中的 **v5.3.1 程序**。已安装的旧版本不会自动更新。
2. 打开脚本，开启顶部 **校对**，修改一句译文或译名，离开输入框完成本次记录。
3. 打开侧栏 **校对 → 修改记录**，点击这条改译旁的 **收藏到 Obsidian**。
4. 预览原文、这次修改前后、角色和上下文，填写作品、路线、心得和标签。
5. 桌面版默认目标是 `E:/Codex/Obsidian/汉化校对积累`；也可选择其他包含 `.obsidian` 的库根目录。
6. 点击 **收藏到库**。保存后可点 **在 Obsidian 打开**；在译间点“刷新”，可看到同一条案例。

这里的“修改后”是你选中的那次历史修改，不一定等于后来又修改过的当前译文。相邻两段和批注来自点击收藏时的文档，卡片中明确标注这一点。位置使用编辑器段落序号，不冒充脚本物理行号。

## 数据与保护

- 输出为 `校对案例/<稳定ID>.md`，兼容译间的 `galnote: 1` 格式；没有另一份同步数据库。
- 同一文档的同一次修改映射到固定 ID。再次点击收藏只返回已有文件，**不更新或覆盖任何已有内容**。如果补写了新心得，可以复制后到已有笔记中追加。
- 桌面绝对路径用于隔离文档；HTML 版拿不到绝对路径时，使用作品名和文件标识区分。HTML 同名文件请填写不同作品名；收藏后更改作品名可能产生新的 ID。
- “原有校对批注”保存在上下文章节，不自动写进“我的心得”。经验卡默认待确认，编辑器的“已通过”不等于经验总结已确认。
- 作品、路线按脚本目录记忆；HTML 版按文件标识记忆。路径、作品和路线偏好单独存入 `obsidian-export.json`（桌面软件目录）或同名 IndexedDB 项，不读取或发送机翻密钥。
- 经验卡独立于编辑器的修改对比保存。后续修改不会自动覆盖已收藏笔记。没有提前记录的旧译文无法凭空恢复。
- 不提供从 Obsidian 反向覆盖游戏脚本，也不自动收藏每次按键。

在 Obsidian / 译间中补充案例时，请保留记录属性、现有章节标题和文本围栏。自由关联页可以单独创建。译间能读取程序格式的经验卡，不能把任意自由 Markdown 当作记录。

## 浏览器版

打开 `dist-single/index.html`（同目录保留构建产生的 Worker 文件）。

- Chrome / Edge 支持目录授权时，点击“选择库目录”，选择包含 `.obsidian` 的库根目录，然后“收藏到库”。权限句柄只在当前页面会话保留，刷新后重新授权。
- 不支持目录授权的浏览器，使用“下载 Markdown”，将文件移入库的“校对案例”目录。若同名笔记已存在，保留旧笔记，避免系统另存为产生重复案例。
- 浏览器直接写入会检查同名文件，并在同源页面之间串行化同一记录的保存；不支持跨应用的并发写入协调。需要严格的并发创建保护时使用桌面版。
- 浏览器“在 Obsidian 打开”按库名定位；如果你有多个同名库，改用桌面版的绝对路径打开。

## 实现与验证

- `src/obsidian.js`：来源匹配、稳定 ID、最多五段的上下文快照、经验卡和 Markdown 格式。无 DOM 依赖。
- `src/obsidian-files.js`：桌面命令、浏览器目录授权与独立偏好。
- `src/obsidian-ui.js`：收藏预览和保存反馈。
- `src-tauri/src/obsidian.rs`：库目录校验、只创建不覆盖的写入和 Obsidian URI 打开。

桌面版先完整写入临时文件，再通过硬链接原子创建目标；同名文件存在时不会替换。库目录需支持硬链接（如 Windows 的 NTFS）。不支持时会明确报错，可改用 Markdown 下载。不会回退到可能覆盖文件的普通写入。

同时修复了输入事件中“先改译文再取旧值”的时序问题：现在首次输入前取快照，单次粘贴也会进入修改记录。

验证命令：

```powershell
node --test tests/obsidian.test.mjs tests/proof.test.mjs tests/exporter.test.mjs
rustc --edition=2021 --test src-tauri/src/obsidian.rs -o "$env:TEMP/galweave-obsidian-tests.exe"
& "$env:TEMP/galweave-obsidian-tests.exe"
```

浏览器流程脚本 `scripts/test-obsidian-browser.mjs` 默认测试本机 `http://127.0.0.1:1421/`，可通过 `GALWEAVE_TEST_URL` 指定页面。需要 Playwright，可通过 `GALNOTE_PLAYWRIGHT` 指定模块路径；`GALNOTE_STORE_MODULE` 可指定译间 `storage.mjs`，验证导出 → 读取 → 编辑的兼容性。全部样例在系统临时目录。

Obsidian 的打开操作采用[官方 Obsidian URI](https://help.obsidian.md/Extending%2BObsidian/Obsidian%2BURI)。需要本机已经安装并启动过 Obsidian，以注册协议。

# Galweave v5.8.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

**零正则的多样例格式设计器**。此前配置离线格式档案要手写 `{text}` / `{id}` / `{name}` 模板；现在**主流程完全不需要懂正则**：给每种布局至少两组原文/译文样例，选中文字点「标为编号 / 角色名 / 正文」，程序据此归纳规则。

- **一个档案可含多种布局**。同一文件里既有带角色名的对话、又有旁白时，加两个布局分别标注即可，不再需要拆成两个档案。
- **多样例互相印证**。两组样例结构不一致时，布局下方**立刻**用中文说明差在哪里（如"第 2 组样例末尾多出一段未被标注的固定文字「」；请检查是否有一处内容忘记标注"），而不是等你点到最后才发现标错。
- **预览表新增命中布局列**。每条记录标明命中的是对话还是旁白，并给出物理行号。
- 旁白行**不会伪造角色名**（旁白本就没有说话人）。

**完全兼容既有档案**：内置档案与你已保存的档案都是 v1 形态，读取行为一字不变；新保存的档案用 v2。两种形态可互相导入，导出文件仍然只含规则、不含脚本文本。

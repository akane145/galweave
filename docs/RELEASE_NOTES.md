# Galweave v5.11.0 — 跨设备记录包 + 保存可靠性

发布日期：2026-09-22。Windows x64 标准桌面版。

本版把「成果静默丢失」的几个口子堵上，并让一份翻译记录能在设备之间搬动。

2026-09-23 本地构建追加 **自定义标点规则**：在「项目 → 标点规则」中加入示例、编辑替换结果，保存后通过「规范化标点」预览并应用；支持撤销，规则随记录包携带。

## 换一台设备接着翻

新增「**导出记录包**」：把一个脚本连同它的全部记录打成一个 `.galweave.json` 文件，传到另一台设备用「**导入记录包**」继续。

包里装着：脚本文本与译文、脚本解析规则（含离线格式档案）、术语表、翻译记忆、快捷片段、批注、修改记录、机翻基线、历史快照、进度统计，以及你上次停在哪一行。

**不含**机翻 API Key、词典源与本机文件路径 —— 设备相关的东西不跟着文件跑，新设备上各自配置一次。

主要用处是**桌面版与浏览器版互通**：浏览器版的数据存在浏览器里，不会随 HTML 文件一起走，以前换到桌面版就只能重来。

## 导入是"加一个独立项目"，不是"覆盖当前"

点导入后会先看到摘要（多少行、多少条批注、多少条记忆、多少份历史），确认后**作为独立标签打开**：

- 当前打开的文档不会被动到，原有未保存的修改仍在；
- 同一个包导入两次会得到两个**互相独立**的标签，先后顺序怎么切都不会互相顶掉；
- 记录包的数据存在本机独立位置，**不会写回任何项目目录，也不会改你的全局术语表**。

保存按钮在这个标签里会变成「导出记录包」—— 它没有对应的磁盘文件，改完再导出一次就能带回另一台设备。

## 导入会逐行核对，不把译文套错行

导入时重新解析脚本，然后**逐行比对原文**。行数不符、某行原文对不上、版本不支持、文件超过 64 MiB、包含危险对象键 —— 一律**整体拒绝并说明原因**。

这条是刻意的：译文是按行套用的，套错行等于把一个角色的台词写进另一个人嘴里，比导入失败严重得多。

## 不自动合并

两台设备各改了一部分后再互相导入，程序**不会**替你合并，而是给你两个独立标签自己对照。自动合并要理解脚本的编号与控制符结构，做不到位的合并比不做更危险。

## 保存更可靠

- **原子写盘**。以前保存直接覆盖原文件，写到一半失败（磁盘满、断电、程序被杀）会留下一个**截断的脚本**，原内容已经没了。现在先写同目录临时文件、落盘、再原子替换 —— 失败时原文件保持原样。
- **替换失败不再冒险**。替换失败（例如文件被游戏或编辑器占用）原本会退化成就地覆盖 —— 那正是"可能截断原文件"的路径，等于在最需要保护的时候把保护绕过去了。现在**失败即失败，原文件完整保留**，并提示关闭占用程序或另存为。
- **目录创建失败不再被报成成功**。目标目录建不出来时仍然返回成功，你以为存下了其实没有。现在如实报错。
- **备份失败会明确告诉你**。以前创建 `.bak` 失败也照样往下写，你以为了有备份、其实没有。现在如实回报（原文件已更新，可用侧栏「历史」找回旧版本）。
- **保存前检测文件被外部改过**。打开时记文件指纹（大小 / 时间 / 内容散列），写盘前比对；被别的程序改过就**不写**，而是问你：另存为新文件（默认）／仍然覆盖／取消。

## 机翻过程更可控

- **可以停止**。以前批量机翻是一个跑到底的循环，按不了停、只能等（或杀进程）。现在有常驻任务面板，**随时可以停**，已完成的行**全部保留**。
- **失败行可以只重试那些行**。面板逐条列出失败行和原因（**点一下跳到那一行**），点「重试失败的行」就只请求它们 —— 已经成功的行不会重复扣费、重复等待。
- **等待期间你改过的译文不会被覆盖**。请求发出后返回前，如果你自己改了某一行，回来的机翻结果会被跳过并计入"已跳过（你改过）"。
- **超时修复**。原来请求超时只保护到"收到响应头"，之后的正文读取没有保护 —— 服务返回响应头然后挂住，请求就永远不返回，连"停止"都停不掉。现在覆盖到正文读完，且可在机翻配置里调整（默认 90 秒）。

## 编码不再被悄悄改掉

- **保存沿用原文件的编码**。以前读入支持多种编码、写出却固定 UTF-8 —— Shift-JIS 的脚本存回去变成 UTF-8，引擎读出来全是乱码，而你看到的是"保存成功"。
- **顶栏显示"读入 → 写出"编码**，不一致时会标出来。点一下可手动纠正，包括**按指定编码重新解码**（脚本显示乱码时的自救入口）。
- **目标编码存不了中文时会拒绝写入**，而不是把字符替换成实体字符。会给你三个出路：改用 UTF-8 保存 / 仍按原编码强制写入 / 取消。
- 可写出的编码：UTF-8（可带 BOM）、Shift-JIS、EUC-JP、UTF-16 LE/BE。浏览器版受限制只能写 UTF-8，界面把其余编码标为不可用。

## 翻译记忆更懂上下文

- **机翻草稿不再被当成标准答案**。以前机翻结果无门槛入库，之后精确命中会自动套用 —— 等于把一次未复核的机翻扩散到全篇，错了就是一片。现在条目分**机翻草稿**与**已确认**，**只有已确认的会被自动套用**；草稿仍在侧栏「建议」里供你挑，并明确标着来源。
- 确认途径：自己改过/重写过的行自动算确认；通过校对的行也算确认。行右键另有「确认这条记忆（以后自动套用）」。
- **同一句原文可以保留不同角色的译法**。galgame 里同一句台词换个角色说就该换个语气，以前同一句只留一条、新译法覆盖旧的。现在按说话人分开保存，侧栏建议会列出该句的**各个角色变体**并标明来源。
- 老记忆库自动兼容：旧条目视为已确认，不会因为这次改动突然不再自动套用。

## 升级说明

退出旧程序后安装或运行新版。升级前建议照常备份脚本和同目录 `.galweave` 数据。

翻译记忆库会从 v1 结构升级到 v2（新增审核状态与说话人字段），**读取时自动迁移**，旧文件不需要手工处理。进度、术语表、词典源、校对批注、历史快照与设置都原样保留。

## 验证

`cargo test --lib` 38 项、`npm test` 1007 项全部通过，`npm run lint` 为 0 error，Vite 生产构建与单文件 HTML 构建均通过。Windows release 编译与 NSIS 打包成功，生成的 exe 已实机启动确认可用。

记录包在真实 Chromium 里跑通了完整往返：导入既有脚本 → 导入记录包 → 变成独立标签且原有修改仍在 → 编辑 → 导出 → 审查导出内容（译文/批注/术语/片段/记忆齐全，**不含 API Key 与本机路径**）→ 重新导入同名包得到第三个独立标签。边界校验也实测生效：行数多一条/少一条、原文被改、超限、`__proto__` 注入全部被拒绝，且全局对象未被污染。

## 已知边界

- **不做 WebDAV / 应用内自动同步**：涉及脚本结构级的冲突合并，本版不做。
- **不做整项目打包**：以「当前脚本及其记录」为单位。

- 同一句的记忆变体最多保留 6 个说话人。

# Galweave v5.10.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

本版是一个**聚焦工作流手感与键盘可用性**的版本，另修一个虚拟列表的高度测量问题。

**侧栏新增「建议」面板**。翻译时最常做的判断是"这一句以前译过没有、机翻给了什么"——以前这两类信息要么在译文框里输入时靠浮层提示，要么得走行右键菜单，都不好在一个地方对比。

现在侧栏多了一个「建议」页签，聚焦任意一行就会列出**该行可用的全部建议**：

- **TM 精确**：翻译记忆里有原句完全一致的条目，直接给出译法。
- **TM 相似**：没有精确命中时，按相似度列出最接近的几条，每条标注百分比。
- **机翻基线**：该行此前跑过的机翻结果（若有）。

每条右侧都有「采用」按钮，点一下写入译文，走的是和以往完全相同的写入路径（可撤销、计入归因、自动存档）。列表只读展示、不自动套用——**要不要采纳始终由你决定**。

**NAME 行的译名框现在键盘可达**。这是一个一直存在的键盘缺口：按 Tab / Enter 切换到 NAME 行时，焦点落在右侧那个**只读**的译文框上，于是纯键盘操作改不了译名，只能回去用鼠标点。

现在 NAME 行会把焦点给到中文译名框（真正可编辑的那个），输入后 Tab 继续走到下一行。**普通行行为不变**——仍然聚焦译文框，行间导航的手感没有改动。

**侧栏页签支持方向键切换**。←/→ 在「项目 / 术语 / 词典 / 建议 / 校对」之间移动，Home/End 跳到首尾。同时页签按 roving tabindex 只让当前项进入 Tab 序列，减少键盘用户切换面板时的 Tab 次数。

**修复：Web 字体加载完成后未重测行高**。自定义字体的字宽与回退字体不同，字体真正生效后行高会变；而虚拟列表此前只在窗口尺寸变化时重测，于是已测行高的模型和实际 DOM 会逐渐对不上，滚动到深处出现错位。现在字体就绪（`document.fonts.ready`）后再重测一次。

# Galweave v5.9.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

**控制符丢失提示改为默认关闭**。原先译文行会逐行报"原文里的 `[r]` 在译文中不见了"——但**断行标签译文本就要按中文长度重新断行**，把它当"丢失"报出来多数是噪音；而且大部分控制符本来就可以删。

现在默认不报。需要时在「主题与字体 → 文本排印」里勾选「核对译文里的控制符丢失」即可开启，开启后仍能检出丢失与全角误输（把 `[r]` 敲成 `［ｒ］`）。

**修复：关闭剧场模式后原文行超出显示边界**（v5.6.0 引入）。

剧场视图下原文列是隐藏的，而"让原文与译文等宽换行"的函数仍在量它的尺寸——量到的全是 0，于是算出一个 566px 的垃圾位移并写进元素的 inline 样式。退出剧场后原文行重新显示，那个残留位移把它整体推出边界（实测右侧溢出 388px）。

已修复：剧场模式下该函数整体跳过，并且量到 0 时一律不写回。**连切三轮 + 剧场中滚动后退出，均无残留。**

**词典的活用还原**。日语对白里全是活用形（食べた、読んでる、行かなかった），而词典按原形（食べる、読む、行く）索引——以前查「食べた」若词典没有这个词条，就是查不到，得自己在脑子里还原。

现在查不到时会自动试原形，并明确告诉你：

> 未直接命中「食べた」→ 已按原形「食べる」显示（食べた → 食べる）

几条设计上的取舍，说明一下：

- **已经直接查到时完全不变**。只有真的查不到才走这一步，所以你现有习惯不受影响。
- **多步还原会显示完整链路**。像「食べさせられなかった」要经过 食べさせる 才能到 食べる，提示里会把链条写出来，顺带当作活用复习。
- **覆盖现代日文的常见活用**：ます/ない/て/た 形、受身、使役、使役受身、たい、ば、たら、ている/ておく 等补助动词、い形容词与な形容词的活用，含 音便（書いた、泳いだ、待った、読んだ）。也认片假名写法（タベタ → たべる）。
- **不做**：古典/文语活用、方言。

**词典结果的联动**。每张结果卡片头部除了 ☆ 收藏，新增两个按钮：

- **🃏 做成 Anki 卡片**：正面只放生词与读音，背面放释义**与当前行的原句、译文、角色名**。边查词边积累语料，语境自动带上，不用手抄。
- **＋ 加入术语表**：预填原文并显示词典释义供参考，**译名留空由你填**——释义是解释、不是译名选择，程序不替你决定。

（按你的要求，**没有**做"把释义直接插入译文"。）

**补上缺失的词典格式文档**。界面里「词典源」页与 HTTP 配置弹窗一直提示"格式说明见 docs/dictionary-plugins.md"，但那个文件并不存在。现在补齐了，内容按代码实际行为写成：JSON 词典字段、HTTP 的字段映射与 `gloss` 可接受的三种形态、MDX/MDD 的支持范围（含**不支持 LZO 压缩与加密词典**这类边界）。

## 升级说明

退出旧程序后安装或运行新版。升级前建议备份脚本和同目录 .galweave 数据。

活用还原是查词时的即时计算，不涉及任何数据迁移；词典源、术语表、收藏与查词历史都保持不变。

## 验证

本次发布前 859 项 Node.js 测试全部通过（本次新增 44 条）。Windows release 编译、MSI 与 NSIS 打包成功，生成的 exe 已实机启动确认可用。

**控制符开关**在浏览器里双向验证：默认不勾选时，故意丢掉 `[r]` 也不出现提示；勾选后同一行立刻提示「控制符「[r]」在译文中不见了」，且设置已落盘。

**剧场视图边界问题**在浏览器里实测复现并确认修复：修复前"开剧场 → 关剧场"后 `.orig` 残留 `left:566px`、右侧溢出 388px；修复后 `left` 全程 `0px`，连续切换三轮、以及在剧场中滚动后退出，均无残留。

词典部分在真实浏览器里做了端到端验证，包括一个**容易出错但必须验的点**：

- **直接命中的原词行为零回归** —— 连提示条都不出现，与改版前一致。
- **未命中时兜底生效** —— 查到原形、显示还原链路。
- **前缀补全不会被误当成命中** —— 这是本功能的关键：MDX 词典在精确未命中时会返回前缀补全（查「食べた」可能给出「食べすぎる」「食べ物」），若按"有结果就算查到"判断，兜底将永远不触发。测试词典里专门放了两个诱饵项，确认它们没有被算作命中。
- 两个联动按钮都走通了**真实链路**：制卡请求发到模拟的 AnkiConnect 并检查了实际发出的字段（正面生词+读音、背面释义，语境随当前行）；加入术语表经弹窗确认后确实写入了术语表。

构建存在既有未使用变量及打包提示，不影响构建完成；本次未进行完整桌面交互回归。

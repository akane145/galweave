# Galweave v5.5.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

**显示宽度校验**。译文行现在同时给出两把尺子：字节数（既有）与**全角字位数**（新增，1 个汉字 = 1，1 个半角字符 = 0.5）。超限时直接给出**折行建议位置**，并列出断点前后的文本，方便对着目标对话框调整。两者共用同一套四段配色（ok / 接近 / 超限），在「主题与字体」里可分别设置上限或关闭。

这两个数回答的是不同问题：字节是「引擎的字节缓冲放不放得下」，宽度是「画面上放不放得下」。引擎按字形排版，所以「60 个半角数字」占 60 字节，却只有 30 个字位。

**规范化标点**（翻译工作区 → 进度组）。一键把连续半角点统一成「……」、破折号统一成「——」、波浪号统一成「～」。应用前会先列出**真正会变的行**供确认，且**只改译文、绝不碰原文**——原文是日文，那些符号是它的原貌。

**行级提示补两类检查**：

- **控制符丢失**：手改译文时把 `[r]` 删掉、或不小心敲成全角的 `［ｒ］`。此前这种情况完全没有提示，但脚本行为会变（机翻链路一直有保护，手动编辑这条路是敞口）。
- **避头尾**：行首出现句读点、行末出现开引号。只在你自己按的换行处判断——自动折行的位置由引擎决定，报了也是噪音。

**机翻语境参考块**。翻译时自动带上当前句**前后各 2 句**作为语境，并标注每句是「已定稿」「待校对」还是「尚未翻译」，让模型知道哪些邻居可信。日语里代词与省略主语常要靠后文才能定，所以前后都取。Sakura 与通用大模型都支持，句数可调、可关闭。

这与既有的「多轮上下文」是两种机制：多轮上下文是把上一轮的原文/译文作为对话轮次喂回（跨句累积），语境块是把眼前这几句的邻居一起发过去。两者可同时生效。

## 升级说明

退出旧程序后安装或运行新版。升级前建议备份脚本和同目录 .galweave 数据。

新增的两项上限（显示宽度、机翻语境句数）默认值已经可用，不需要额外设置；想要更贴近自己的目标引擎，可在「主题与字体 → 文本排印」里调整。

## 验证

本次发布前 643 项 Node.js 测试全部通过。Windows release 编译、MSI 与 NSIS 打包成功，生成的 exe 已实机启动确认可用。

显示宽度、规范化标点、控制符检测、避头尾四项在浏览器形态下做了完整交互验证：折行建议在 30 字位处准确断开（36 字位 → 断成 30 + 6）、规范化后译文 `...`→`……` 且原文一字未动、控制符丢失报出「`[r]` 不见了（缺 2 个）」、行首顿号报出避头尾提示。

内部整理：`main.js` 拆分出 `src/ui/`（进度统计编排、机翻配置表单），并新增 `tests/ui-modules.test.mjs` 把模块路径错误提前到测试阶段（此前这类错误只有打包时才会暴露）。

# Galweave v5.3.1

发布日期：2026-09-17。Windows x64 标准桌面版。

## 本版重点

修改记录完整保存所有已修改行，只比较首次校对修改前与最新文本。同一句反复输入不会产生一串中间版本，改回最初文本后不再显示差异。取消 500 条保存上限与 50 条显示上限。

支持校对意见 Markdown 导出和 Obsidian 收藏，相关操作见使用教程及 Obsidian 联动文档。

## 下载文件

- Galweave_5.3.1_x64-setup.exe：安装包。
- Galweave_5.3.1_x64.exe：直接运行程序。
- SHA256SUMS.txt：以上文件的 SHA-256 校验值。
- GitHub 自动生成的 Source code：与发布标签一致的源码。

## 升级说明

退出旧程序后安装或运行新版。升级前建议备份脚本和同目录 .galweave 数据。已有修改记录会自动合并；旧版已截断的记录无法恢复。Obsidian 已收藏笔记不会因后续修改自动覆盖。

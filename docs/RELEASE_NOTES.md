# Galweave v5.6.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

**角色人设表**（侧栏「术语」→ 角色人设）。为每个角色记录**性别 / 年龄**、**自称**（ボク、私、俺）、**语气 / 口吻**（冷峻干练、关西腔、傲娇）与备注。之后翻译该角色说话的行时，这些设定会自动进入提示词，让语气与用词从头到尾保持一致，而不是每句各说各话。Sakura 与通用大模型都支持。

一个使用提醒：人设靠**脚本解析出的说话人**来匹配。若当前文本没有可识别的说话人前缀（如 `☆编号☆角色名☆台词`），人设不会生效——这种情况下面板会给出**明确的黄色警告**，不会让你以为设了却没起作用。

**剧场视图**（顶栏「剧场」）。以角色气泡的形态只读阅读译文：隐藏原文列与编辑控件，译文放大、行距放宽，不同角色用不同颜色区分，旁白则用左侧细线单独分层。点任意气泡就回到表格编辑，不用先去找按钮。

**历史快照多了两种保险**：

- **改动累积触发**：自上次留档起改满 50 行就留一份，即使还没到 5 分钟的时间间隔。连着翻几十行可能只花两三分钟，旧逻辑一份不留，之后一次批量误操作就没有后悔药。
- **手动留档**：行右键菜单新增「留存当前版本」，随时打一个点。

## 升级说明

退出旧程序后安装或运行新版。升级前建议备份脚本和同目录 .galweave 数据。

角色人设存在项目术语表（`glossary.json`）里，与既有的术语、人名同层。旧版术语表可直接使用，新增的 personas 字段缺失时按空表处理，无需迁移。

本次发布前 663 项 Node.js 测试全部通过。Windows release 编译、MSI 与 NSIS 打包成功，生成的 exe 已实机启动确认可用。

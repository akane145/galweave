# Galweave v5.7.0

发布日期：2026-09-18。Windows x64 标准桌面版。

## 本版重点

**Anki 一键制卡**。译文行右键 →「做成 Anki 卡片」，把这一行的【生词 + 假名 + 释义 + 原句 + 译文】送进 Anki，边翻译边积累语料。

卡片的正面只放生词与假名，释义、原句、译文都放背面——语境是帮助你回想与理解的锚点，放正面就直接泄题了。标签会自动从文件名与项目目录生成（空格转下划线）。

需要 **Anki 正在运行**且已安装 **AnkiConnect** 插件。牌组、笔记类型与接口地址在侧栏「术语 → Anki…」里设置，连得上时会自动拉取你库里的实际牌组列表。

**Obsidian 双向联动**（两条新通路，都只碰术语，不碰脚本）：

- **术语导入**.md：术语面板的「导入」现在也接受 Obsidian 笔记，读三种写法——frontmatter 的 `terms`/`names`、表格两列、`源 :: 译` 的列表配对。`[[双链]]` 会被收集为"待补译名"（笔记里写双链表示这是需要保留原文的专有名词，但没给译名），补上译名后再导一次即可。
  为避免把散文当术语，只认这些有明确结构的写法，并对长度设限。**已有的译名一律保留**，只新增不覆盖——笔记多为参考资料，静默覆盖比漏导更危险。
- **双语对照 Markdown 导出**：导出下拉新增该格式，产出带 frontmatter 与 callout 结构的台本，在 Obsidian 里直接可读。对白用 `quote`/`success`，未译条目用 `warning`/`danger` 明确标出。

按 `docs/obsidian-integration.md` 的既有约定，**仍然不提供从 Obsidian 反向覆盖游戏脚本**；术语导入是唯一允许的反向路径，且只写术语表。

## 升级说明

退出旧程序后安装或运行新版。升级前建议备份脚本和同目录 .galweave 数据。

Anki 与术语导入都是新增通路，不改动既有数据格式；旧术语表与旧笔记无需迁移。

# Galweave v5.3.1 使用指南

## 开始校对

1. 从 GitHub Releases 下载并运行桌面版，首次处理脚本前保留备份。
2. 打开文本文件。常规格式使用 ☆ 原文、★ 译文；其他格式先通过格式识别检查结果，再进行编辑。
3. 开启校对模式，编辑译文或译名，按需要添加批注、标记有问题或已通过。
4. 在修改记录中检查最初文本与最新文本，完成后保存或导出。

## 修改记录

- 只在校对模式下记录修改；停止输入约 1200ms 或离开输入框后结算。
- 同一行同一字段合并为一条对比，保留第一次修改前的文本与最新文本。
- 不限制 500 条，不再只显示 50 条；译名与正文分别记录。
- 改回最初文本后差异记录消失；还原操作可通过撤销恢复。
- 保存、切换标签或关闭校对模式时会结算最后输入。
- 旧记录会合并，但旧版已截断的文本无法恢复。

## 格式识别与保存

默认结构为原文行及可选译文行，编号和引擎标记用于匹配与还原。遇到不同导出格式，先在格式/规则设置中检查自动识别结果；必要时配置手工规则。使用脚本副本验证导出结果后再用于游戏项目。

文本保存与导出使用 UTF-8；不要假定原始 Shift-JIS、EUC-JP 或 UTF-16 编码会被保留。原文在编辑器中只读。

## 词典与术语

词典支持 MDX/MDD、本地 JSON 和 HTTP 来源。桌面版按词典路径读取资源，相关 MDD 与外部资源应保持原来的目录关系。添加后通过划词或侧栏查询确认可用。

项目术语表可用于统一人名和用语；批量应用前建议保存。机翻可使用通用大模型或 Sakura，服务地址与凭据在本机配置。

## 校对意见与 Obsidian

侧栏可以导出校对意见，也可以将选定改译收藏到 Obsidian。详细步骤见 [Obsidian 联动](obsidian-integration.md)。已收藏笔记不会被后续编辑自动覆盖。

## 数据与备份

桌面校对数据位于源文件目录的 .galweave 内；浏览器使用 IndexedDB。清除进度会删除对应校对数据。升级或批量处理前备份脚本和 .galweave 目录。

源码仓库不分发测试游戏文本；本地样本可继续放在 test text/，该目录已被 Git 忽略。

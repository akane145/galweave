§3字体系统

四族分工。核心：原文明朝（衬线）／ 译文黑体（无衬线） —— 字体族差异是比颜色更可靠的语义信号，截图转灰度依然可分。 等宽只服务数字与结构符号，不用于日文原文（假名在等宽字形里字面小、字重轻）。

§4间距系统（8px 主网格 + 4px 半步）

纯 8px 网格在专业工具里不够用 —— 图标与文字间隙（4–6px）、标签内距、紧凑控件内距都落在 8 的倍数之间， 强行对齐会牺牲信息密度（违反设计原则 3）。8 的倍数用于布局间距，4 的奇数倍（4 / 12 / 20）只用于控件内部微调。

§8交互反馈

六态矩阵 + 字节数四段阈值。在下框输入，观察 70% / 90% / 100% 的三段跳变；超限时停止输入 400ms 后触发呼吸（循环最多 3 次）。

§8.3 字节数指示器 · 四段阈值（--byte-limit:120）
0 / 120B · UTF8
<70% --text-dim ／ 70–90% --text-mid ／ 90–100% --st-pending ／ >100% --st-issue + 延迟 400ms 呼吸 ×3。 不用抖动 —— 打断输入流且在虚拟滚动里触发重排。
⚠️ 阈值口径依赖阻塞项 Q3（目标引擎文本框规格）；galgame 引擎常按 Shift-JIS 算（全角 2 字节），UTF-8 下中文 3 字节，指示器必须标注口径。

§10明确不做的事

❌ 不做理由替代方案
侧栏毛玻璃 backdrop-filter长列表滚动掉帧 + 降低对比度，与长时间阅读直接冲突分层背景 + 1px 边框 + 顶部内高光
高饱和实心主按钮满屏色块 = 网页感--accent-dim 底 + accent 文字
抖动 / shake 动效打断输入流，触发重排延迟 400ms 呼吸 ×3，仅作用于指示器本体
全文统一圆角容器变钝，失去工具感容器 0–2px / 控件 4px / 浮层 8–10px
日文原文用等宽字体假名字面缩小、字重变轻等宽只服务数字与结构符号
outline 做焦点环不跟圆角、无法外发光、密集列表粘连box-shadow 模拟 ring
状态色用红/黄/绿老三样色相跨度不足，色觉障碍糊成一片琥珀 / 朱橙 / 青绿 + 形状编码
hover 改尺寸 / 缩放虚拟滚动里布局抖动只改颜色与阴影
webfont CDN（Google Fonts）Tauri 离线是硬需求，CSP 也会拦系统字体栈 + 可选内置子集
z-index: 9999层级失控，无法维护§6.1 层级表（0–80）
